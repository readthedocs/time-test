<a id="basic-concepts" class="tsd-anchor"></a><h2 class="tsd-anchor-link">Basic Concepts<a href="#basic-concepts" aria-label="Permalink" class="tsd-anchor-icon"><svg viewBox="0 0 24 24"><use href="assets/icons.svg#icon-anchor"></use></svg></a></h2><p>To use Zoom Rivet effectively, you should understand three important concepts: authentication, listening to events, and using the Web API.</p>
<a id="authentication" class="tsd-anchor"></a><h3 class="tsd-anchor-link">Authentication<a href="#authentication" aria-label="Permalink" class="tsd-anchor-icon"><svg viewBox="0 0 24 24"><use href="assets/icons.svg#icon-anchor"></use></svg></a></h3><p>Zoom Rivet handles authentication for developers. All you have to do is provide your app's <code>ClientId</code> and <code>ClientSecret</code>. See the matrix in the table below to better how authentication works in each Rivet module:</p>
<table>
<thead>
<tr>
<th>Module</th>
<th>Auth Type</th>
</tr>
</thead>

<tr>
<td>Chatbot</td>
<td><a href="https://developers.zoom.us/docs/team-chat-apps/installation-and-authentication/#authentication" target="_blank" class="external">Client Credentials</a></td>
</tr>
<tr>
<td>Video SDK</td>
<td><a href="https://developers.zoom.us/docs/video-sdk/api-request/" target="_blank" class="external">JWT</a></td>

<td>Team Chat, Meetings, Phone, Accounts, Users</td>

</tr>
</tbody>
</table>
<a id="listening-to-events" class="tsd-anchor"></a><h3 class="tsd-anchor-link">Listening to Events<a href="#listening-to-events" aria-label="Permalink" class="tsd-anchor-icon"><svg viewBox="0 0 24 24"><use href="assets/icons.svg#icon-anchor"></use></svg></a></h3><p>To listen to events sent to your app, you can use the <code>event()</code> method in the <code>webEventConsumer</code> property. This method can be used to listen to any supported Zoom webhook event, like a slash command shown below.</p>
<p>This method receives a required parameter of <code>string</code>, which filters out webhook events that do not match.</p>
<pre><code class="javascript"><span class="hl-0">chatbotClient</span><span class="hl-1">.</span><span class="hl-0">webEventConsumer</span><span class="hl-1">.</span><span class="hl-6">event</span><span class="hl-1">(</span><span class="hl-3">&quot;bot_notification&quot;</span><span class="hl-1">, (</span><span class="hl-0">response</span><span class="hl-1">) </span><span class="hl-4">=&gt;</span><span class="hl-1"> {</span><br/><span class="hl-1">  </span><span class="hl-4">const</span><span class="hl-1"> </span><span class="hl-5">payload</span><span class="hl-1"> = </span><span class="hl-0">response</span><span class="hl-1">.</span><span class="hl-0">payload</span><span class="hl-1">;</span><br/><span class="hl-1">  </span><span class="hl-0">console</span><span class="hl-1">.</span><span class="hl-6">log</span><span class="hl-1">(</span><span class="hl-0">payload</span><span class="hl-1">);</span><br/><span class="hl-1">});</span>

<a id="event-shortcuts" class="tsd-anchor"></a><h3 class="tsd-anchor-link">Event shortcuts<a href="#event-shortcuts" aria-label="Permalink" class="tsd-anchor-icon"><svg viewBox="0 0 24 24"><use href="assets/icons.svg#icon-anchor"></use></svg></a></h3><p>Rivet provides built-in shortcuts that enable you to execute complex processes in just a few lines of code.</p>
<a id="chatbot-1" class="tsd-anchor"></a><h4 class="tsd-anchor-link">Chatbot<a href="#chatbot-1" aria-label="Permalink" class="tsd-anchor-icon"><svg viewBox="0 0 24 24"><use href="assets/icons.svg#icon-anchor"></use></svg></a></h4><a id="onslashcommand" class="tsd-anchor"></a><h5 class="tsd-anchor-link"><code>onSlashCommand()</code><a href="#onslashcommand" aria-label="Permalink" class="tsd-anchor-icon"><svg viewBox="0 0 24 24"><use href="assets/icons.svg#icon-anchor"></use></svg></a></h5><p>Your app can use the <code>onSlashCommand()</code> method to listen to incoming slash command requests.
Use the <code>say()</code> method to respond to slash commands. It accepts a string or <a href="https://developers.zoom.us//docs/team-chat-apps/customizing-messages/" target="_blank" class="external">App Card JSON</a>.</p>
<pre><code class="javascript"><span class="hl-0">chatbotClient</span><span class="hl-1">.</span><span class="hl-0">webEventConsumer</span><span class="hl-1">.</span><span class="hl-6">onSlashCommand</span><span class="hl-1">(</span><span class="hl-3">&quot;SLASH_COMMAND&quot;</span><span class="hl-1">, </span><span class="hl-4">async</span><span class="hl-1"> ({ </span><span class="hl-0">say</span><span class="hl-1">, </span><span class="hl-0">payload</span><span class="hl-1"> }) </span><span class="hl-4">=&gt;</span><span class="hl-1"> {</span><br/><span class="hl-1">  </span><span class="hl-0">console</span><span class="hl-1">.</span><span class="hl-6">log</span><span class="hl-1">(</span><span class="hl-0">payload</span><span class="hl-1">);</span><br/><span class="hl-1">  </span><span class="hl-2">await</span><span class="hl-1"> </span><span class="hl-6">say</span><span class="hl-1">(</span><span class="hl-3">&quot;Hello World!&quot;</span><span class="hl-1">);</span><br/><span class="hl-1">});</span>
</code><button type="button">Copy</button></pre>

<a id="onbuttonclick" class="tsd-anchor"></a><h5 class="tsd-anchor-link"><code>onButtonClick()</code><a href="#onbuttonclick" aria-label="Permalink" class="tsd-anchor-icon"><svg viewBox="0 0 24 24"><use href="assets/icons.svg#icon-anchor"></use></svg></a></h5><p>Your app can listen to button clicks and respond using the <code>onButtonClick()</code> method. This method takes in a string, which filters button action values.
You can respond with the <code>say()</code> function, which accepts a string or <a href="https://developers.zoom.us//docs/team-chat-apps/customizing-messages/" target="_blank" class="external">App Card JSON</a>.</p>
<pre><code class="javascript"><span class="hl-0">chatbotClient</span><span class="hl-1">.</span><span class="hl-0">webEventConsumer</span><span class="hl-1">.</span><span class="hl-6">onButtonClick</span><span class="hl-1">(</span><span class="hl-3">&quot;BUTTON_VALUE&quot;</span><span class="hl-1">, </span><span class="hl-4">async</span><span class="hl-1"> ({ </span><span class="hl-0">say</span><span class="hl-1">, </span><span class="hl-0">payload</span><span class="hl-1"> }) </span><span class="hl-4">=&gt;</span><span class="hl-1"> {</span><br/><span class="hl-1">  </span><span class="hl-0">console</span><span class="hl-1">.</span><span class="hl-6">log</span><span class="hl-1">(</span><span class="hl-0">payload</span><span class="hl-1">);</span><br/><span class="hl-1">  </span><span class="hl-2">await</span><span class="hl-1"> </span><span class="hl-6">say</span><span class="hl-1">(</span><span class="hl-3">&quot;Hello World!&quot;</span><span class="hl-1">);</span><br/><span class="hl-1">});</span>
</code><button type="button">Copy</button></pre>
